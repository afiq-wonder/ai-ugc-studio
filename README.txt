QUICK DEPLOY WITH GITHUB PAGES
1. Create a new GitHub repository named: ai-ugc-studio
2. Upload all files and folders from this package.
3. Open repository Settings.
4. Open Pages.
5. Under Build and deployment, choose:
   Source: Deploy from a branch
   Branch: main
   Folder: / (root)
6. Save and wait for the GitHub Pages address.
7. Open that address in Safari on iPad.
8. Tap Share → Add to Home Screen.

IMPORTANT
GitHub Pages must serve the files over HTTPS for installation and offline caching.
This test build does not upload user images or use any AI API.
